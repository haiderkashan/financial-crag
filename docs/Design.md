# Visual & Aesthetic Guidelines

## 1. The Anti-AI Vibe

Most AI applications look exactly the same: dark mode, purple gradients, rounded corners, and generic icon sets. **This project must reject that aesthetic entirely.**
The look should feel like a high-end financial editorial (think Financial Times mixed with a brutalist Bloomberg Terminal).

## 2. Strict Constraints

- **NO Icons:** Completely ban libraries like `lucide-react`, `heroicons`, or FontAwesome. Use typography, symbols (like `+`, `-`, `->`), and structural layout to denote actions.
- **NO Gradients:** Solid colors only. Ban all purple, indigo, and cyan defaults.
- **NO "Chatbot Bubbles":** Format the chat as a running analytical document or terminal log, not iMessage-style bubbles.

## 3. Typography (Crucial)

Do NOT use Inter, Roboto, or standard system fonts.

- **Primary Text (Prose):** Use a sharp, elegant serif like **Newsreader** or **EB Garamond**.
- **Data, Code, & Tables:** Use a distinct monospace font like **JetBrains Mono** or **Fira Code**.
- **Headers/UI Elements:** Use a stark, geometric sans-serif like **Geist**, **Space Grotesk**, or **Helvetica Neue**.

## 4. Color Palette

- **Background:** Off-white/parchment (`#F7F7F5`) or a very stark industrial gray (`#111111`) if doing dark mode.
- **Text:** Pure Black (`#000000`) or Off-Black (`#1A1A1A`).
- **Accent:** A single, sharp accent color for active states/highlights. Use a stark industrial yellow/mustard (e.g., `#E5A823` or `#FFD700`). Use it sparingly for maximum impact.
- **Borders:** Sharp, 1px solid black or dark gray borders. Minimal to no border-radius (square corners).
